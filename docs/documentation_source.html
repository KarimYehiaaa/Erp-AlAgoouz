1. نظرة عامة ورؤية المشروع

نظام بن العجوز ERP هو منصة سحابية وهجينة متكاملة تم تصميمها وتطويرها خصيصاً لإدارة عمليات سلاسل المقاهي ومحامص وتجارة البن بالتجزئة والجملة. يغطي النظام كافة الدورات المستندية من الشراء واستيراد حبوب البن الخضراء، عمليات التحميص والخلط والتعبئة (BOM & Manufacturing)، إدارة نقاط البيع السريعة (POS)، دورة المبيعات والعملاء، إدارة الخزائن والشركاء، ونظام الموارد البشرية والرواتب.

⚡ استمرارية العمل دون إنترنت (Offline First)

دعم كامل لتسجيل مبيعات الكاشير وحركات المخزون على قاعدة بيانات IndexedDB المحلية مع مزامنة ذكية فور عودة الاتصال.

🔒 أمان مالي وتدقيق صارم (Audit Log)

تسجيل كامل على مستوى الصف (Row-Level Auditing) لجميع العمليات المالية وحركات المخزون مع تشفير AES-256 للبيانات الحساسة.

☕ إدارة تصنيع وخلطات البن المتقدمة

محرك شجري متقدم لحساب التكلفة الفعالة للخلطات ونسب الهالك أثناء التحميص ومراقبة طبقات التكلفة (WAC & FIFO).

🖨️ تكامل العتاد الفيزيائي المباشر (Hardware POS)

دعم الطباعة الحرارية المباشرة (WebUSB ESC/POS) بدون نوافذ متصفح، قفل وفتح درج النقدية التلقائي، وقراءة الباركود السريع.

4. الموديولات الرئيسية وقواعد العمل (Business Modules)

1. موديول نقاط البيع والكاشير (POS & Cashier Management)

شاشة كاشير متطورة بنظام Categories-First تتيح إدخال الطلبات بسرعة فائقة:

  • تخصيص البن المتقدم: خيارات فورية لتحديد درجة الطحن (تركي ناعم، إسبريسو، V60، فرنش برس)، درجة التحميص (فاتح، وسط، غامق)، ونوع التحويجة (سادة، حبهان، مستكة، ملكي).
  • البيع بالأوزان القياسية: دعم أوزان سريعة (⅛ ثمن، ¼ ربع، ½ نصف، 1 كجم) أو إدخال وزن الميزان الرقمي مباشرة.
  • تعليق واسترجاع الفواتير (Hold/Resume Orders): حفظ الفواتير المعلقة بضغطة زر لخدمة طوابير العملاء دون تعطيل.

2. موديول المخازن والتصنيع والخلطات (Inventory & BOM Recipes)

  • الخصم التلقائي للمكونات: عند بيع مشروب أو خلطة بن، يتم تفكيك الوصفة برمجياً وخصم الخامات الأولية (حبوب بن خام، حبهان، حليب، سيرب) بدقة متناهية.
  • حساب تكلفة الإنتاج والفاقد (Roasting Yield Loss): احتساب نسبة الرطوبة والهالك المفقود أثناء عملية التحميص لضمان التكلفة الدقيقة للكيلو المحمص.
  • الجرد الذكي (Stocktake): مقارنة الرصيد الدفتري بالرصيد الفعلي واحتساب الفروقات وتوليد قيود التسوية آلياً.

3. موديول الحسابات والشركاء والخزائن (Finance & Treasury)

  • شجرة الحسابات والقيود اليومية المزدوجة (Double-Entry Bookkeeping).
  • حسابات الشركاء وتوزيع الأرباح: متابعة رأس مال كل شريك، المسحوبات الشهرية، ونسب الأرباح الدورية.
  • الخزائن والورديات: تتبع عهدة الكاشير بداية ونهاية كل وردية مع حساب الفائض والعجز النقدي.

4. موديول الموارد البشرية والرواتب (HR & Payroll)

  • حساب التأخير والغياب آلياً بناءً على الورديات وجداول الحضور.
  • إدارة السلف وأقساطها الشهرية وخصمها التلقائي من مسير الرواتب.
  • ترحيل صافي الرواتب تلقائياً إلى بنود المصروفات العامة.

5. هيكل قاعدة البيانات والأمان (Database & Security)

🔒 مبدأ عدم فقدان البيانات والنزاهة الثنائية (Local/Online Parity)
تم بناء قاعدة البيانات وفق معايير ACID باستخدام تجمعات اتصال معزولة (Connection Pool)، مع قفل الصفوف الحرج SELECT ... FOR UPDATE أثناء عمليات البيع والإنتاج لضمان عدم حدوث تضارب في الأرصدة (Zero Race Conditions).
الجدول الأساسي المحتوى والوظيفة العلاقات والربط (Relationships)
users & roles المستخدمين، كلمات المرور المشفرة (Bcrypt)، والأدوار (Admin, Manager, Cashier). ربط M2M مع جدول permissions
products المنتجات، أسعار البيع والشراء، تصنيف الصنف، والوحدات. مرتبط بـ product_categories و product_units
inventory أرصدة المخزون الفعلية لكل صنف في كل مخزن/فرع. مرتبط بـ warehouses و products
recipes & recipe_items خلطات البن ومكونات الوصفات ومعاملات التحويل لكل منتج مركب. مرتبط بـ products (المكون والمنتج النهائي)
sales & sale_items فواتير المبيعات، التاريخ، الكاشير، طريقة الدفع، والخصومات. مرتبط بـ customers و users و products
purchases & suppliers فواتير المشتريات، الموردين، حسابات الآجل، وتحديث المتوسط المرجح. مرتبط بـ suppliers و inventory
db_row_audits سجل تدقيق كامل وغير قابل للحذف لكل عمليات التعديل والحذف في النظام. مسجل بواسطة تريجرز قاعدة البيانات تلقائياً

6. متطلبات بيئة التشغيل والتثبيت (Deployment & Setup)

💻 متطلبات الخادم المحلي (Local Server)

Node.js ≥ v20.0, PostgreSQL ≥ 15, 8GB RAM, Windows 10/11 أو Linux Ubuntu 22.04.

🌐 متطلبات السحابة (Cloud Production)

PostgreSQL على Supabase/AWS RDS، استضافة Vercel/Docker مع تأمين SSL مشفر.

أوامر التشغيل السريعة:

# 1. تثبيت الحزم للواجهة الأمامية والخلفية
npm install

# 2. تنفيذ الترحيلات وبناء قاعدة البيانات
npm run migrate

# 3. بناء الواجهة للإنتاج وتشغيل السيرفر الموحد
npm run build --prefix frontend
npm start --prefix backend
# المنفذ الافتراضي الموحد: http://localhost:3000
