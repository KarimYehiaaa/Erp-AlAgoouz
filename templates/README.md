# قالب استيراد المبيعات

حمّل القالب من النظام: **المبيعات → قالب Excel**

أو من API: `GET /api/v1/sales/template`

## أعمدة ورقة «مبيعات»

| العمود | إلزامي | مثال |
|--------|--------|------|
| تاريخ_البيع | نعم | 2026-05-21 |
| نوع_البيع | نعم | branch أو wholesale |
| المبلغ_جنيها | نعم | 1500.50 |
| كود_العميل | لا | C-002 |
| حالة_الدفع | لا | paid |
| طريقة_الدفع | لا | cash |
| ربح_اختياري | لا | 200 |
| ملاحظات | لا | مبيعات اليوم |
