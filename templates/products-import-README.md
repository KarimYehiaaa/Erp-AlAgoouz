# قالب استيراد المنتجات

من النظام: **المنتجات → قالب Excel**

## الأعمدة

| العمود | إلزامي | مثال |
|--------|--------|------|
| رمز_SKU | نعم | TC-100 |
| الباركود | لا | 6281001000100 |
| اسم_المنتج | نعم | بن تركي - 250 جرام |
| التصنيف | نعم | turkish-coffee أو بن تركي |
| الوحدة | لا | كيس |
| سعر_الشراء | لا | 45 |
| سعر_البيع | نعم | 65 |
| سعر_الجملة | لا | 58 |
| حد_ادنى_مخزون | لا | 10 |
| نشط | لا | 1 أو 0 |
| مخزون_رئيسي | لا | 50 |
| مخزون_المحل | لا | 15 |
| وصف | لا | نص |

إذا وُجد نفس `رمز_SKU` يتم **تحديث** المنتج وإضافة المخزون للكميات المذكورة.
