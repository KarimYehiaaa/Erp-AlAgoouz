# سجلات التدقيق التاريخية

الملفات في هذا المجلد لقطات تدقيق أُعدّت في تواريخ سابقة، وليست مواصفات تشغيل حالية. أي وصف لدعم فروع تجارية متعددة أو لصلاحيات مبنية على الفروع قد تجاوزه نموذج النظام الحالي: محل واحد، ومخازن متعددة بنطاق صلاحيات مبني على `warehouse_id`.

قبل اعتماد أي ملاحظة من تقرير قديم، تحقّق من الكود الحالي و`CONTEXT.md` وسجل الترحيلات؛ قد تكون المشكلة أُصلحت أو تغيّر التصميم منذ كتابة التقرير.
