# 🛡️ سياسات ومعايير الأمان لنظام بن العجوز (Security Architecture & Policy)

## 📌 1. سياسة الاتصال بالخادم المعتمد (Trusted Server URL Policy)
- **بروتوكول التشفير الإلزامي (HTTPS)**: يُمنع في بيئة الإنتاج استخدام أي اتصال غير مشفر (`http://`) إلى خوادم مركزية أو خارجية.
- **قائمة النطاقات الموثوقة (Allowlist)**:
  - النطاقات الرسمية المعتمدة: `*.alagoouz.com` و `*.binalagoouz.com`.
  - النطاقات الممررة صراحة عبر متغيرات البيئة الآمنة (`POS_TRUSTED_SERVER_URLS`, `VITE_TRUSTED_SERVER_URLS`).
  - بروتوكول `http://` مسموح به **حصرياً** في بيئة التطوير على مضيف محلي (`localhost`, `127.0.0.1`).
- **الفشل المغلق (Fail-Closed)**: أي عنوان خادم غير مطابق يتم رفضه فوراً وتُعرض الرسالة الموحدة:
  > **"عنوان الخادم غير موثوق به لهذا الجهاز"**

---

## 🔒 2. حماية بيانات الجلسات والتخزين المشفر (Secure Session Storage)
- **التشفير بالعتاد (OS-Level safeStorage / DPAPI)**: يتم تشفير توكنات الجلسة وبيانات المستخدم عند التخزين المحلي باستخدام واجهة `safeStorage` في Windows.
- **منع التخزين النصي المكشوف**: تم حظر وتطهير مفاتيح `pos_token` من `localStorage` نهائياً لمنع استخراج التوكن عبر أي هجمات XSS محتملة.
- **البديل الآمن (In-Memory Fallback)**: في حال عدم توفر عتاد التشفير، تُحفظ الجلسة في الذاكرة الحية فقط ويُمنع تخزينها كنص عادي على القرص.
- **الكتابة الذرية (Atomic File Writes)**: حفظ البيانات عبر ملف مؤقت واستبدال فوري لمنع تلف ملف الجلسات عند انقطاع التيار الكهربائي المفاجئ.

---

## 🛡️ 3. تحصين اتصال العمليات البينية في Electron (IPC Security Layer)
- **التحقق من الإطار الرئيسي (`validateIpcSender`)**: تُرفض أي رسائل أو طلبات IPC قادمة من إطارات فرعية (`iframes`)، وتُقبل حصرياً من الإطار الرئيسي للمصادقة.
- **التحقق من المسار الأصلي (Origin Verification)**: حصر معالجة الـ IPC في الإنتاج على المسار الحقيقي للحزمة المجمعة (`file:///.../dist/index.html`).
- **مكافحة التلوث البرمجي (Prototype Pollution Prevention)**: فحص كافة الحمولات لمنع حقن مفاتيح `__proto__` أو `constructor` أو `prototype`.
- **حجب الأخطاء الحساسة (Error Sanitization)**: تطهير رسائل الأخطاء قبل إعادتها للريندرر لإخفاء مسارات نظام التشغيل واستعلامات قاعدة البيانات.

---

## 🌐 4. أمان النوافذ والتصفح (Window & Webview Security)
- **حظر النوافذ المنبثقة**: تطبيق `setWindowOpenHandler` لحظر فتح أي نوافذ داخلية، وتوجيه الروابط الخارجية الآمنة فقط إلى متصفح النظام الافتراضي.
- **حظر التنقل غير المصرح به (`will-navigate`)**: منع توجيه النافذة لمواقع خارجية غير موثوقة.
- **حظر الـ Webviews (`will-attach-webview`)**: منع إرفاق أي عنصر `<webview>` داخل الريندرر نهائياً.
