# معمارية نظام بن العجوز ERP

## نظرة عامة

```
┌─────────────────────────────────────────────────────────────┐
│                    Vue.js 3 Frontend (RTL)                   │
│  Dashboard │ POS │ Products │ Inventory │ Reports │ ...     │
└──────────────────────────┬──────────────────────────────────┘
                           │ REST API / JWT
┌──────────────────────────▼──────────────────────────────────┐
│              Express.js Backend (Modular)                    │
│  Routes → Controllers → Services → PostgreSQL               │
└──────────────────────────┬──────────────────────────────────┘
                           │
┌──────────────────────────▼──────────────────────────────────┐
│                    PostgreSQL Database                       │
└─────────────────────────────────────────────────────────────┘
```

## طبقات Backend

| الطبقة | المسؤولية |
|--------|-----------|
| Routes | تعريف المسارات والصلاحيات |
| Controllers | معالجة HTTP |
| Services | منطق الأعمال |
| Database | استعلامات SQL |

## الترابط بين الأقسام

- **البيع (POS)** → يخصم المخزون → يسجل `stock_movements` → يُنشئ `invoice` + `payment` → يُحدّث Dashboard
- **المرتجع** → يُعيد الكمية للمخزون → يُحدّث حالة البيع
- **تحويل المخزون** → بين المخازن التابعة للمحل الواحد
- **العملاء (جملة)** → رصيد + حد ائتماني

## الأدوار والصلاحيات

| الدور | الوصول |
|-------|--------|
| admin | كامل |
| manager | كل شيء عدا المستخدمين والإعدادات |
| cashier | POS + عملاء + فواتير |
| warehouse | مخزون + منتجات |

## حدود النطاق الحالية

- النظام يخدم محلًا تجاريًا واحدًا فقط؛ لا توجد كيانات فروع أو عزل مستأجرين.
- يمكن للمحل إدارة عدة مخازن، ويُستخدم المخزن لتحديد نطاق المخزون والوردية والتقارير التشغيلية.
- تُوحّد سجلات البيع القطاعي تحت نوع `retail`؛ لا يُستخدم نوع بيع أو كيان تنظيمي باسم الفرع.
- أي مستند قديم يذكر دعم الفروع المتعددة لا يصف التصميم الحالي.

## توسع مستقبلي

- أجهزة ومخازن إضافية للمحل الواحد، دون تحويل المخازن إلى فروع تجارية
- Barcode / QR Scanner
- تصدير Excel
- PDF API
- نسخ احتياطي تلقائي
